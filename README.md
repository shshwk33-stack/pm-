## 자료 범위

이 브랜치는 발표자료 전달용입니다. 기존 프로젝트의 연구모델, 원본 데이터, 도로 OD, SQLite DB 및 저장된 연구결과를 수정하지 않았습니다. API 키나 비밀 설정은 포함하지 않습니다.

실제 관측 결과와 운영사 소속을 변경한 가상실험을 구분하고, A→B 운송대상 전환 효과·B→C 순수 Pooling 효과·A→C 전체 도입 효과를 구분해 설명합니다.

## 제출 분량 확인

대회 공고는 **표지 포함 15쪽 이내, 10MB 이내**입니다. 요청한 본문 15장에 표지와 참고문헌을 더하면 17쪽이 됩니다. ZIP에 본문 13장 압축본을 함께 넣었으므로 제출할 때 분량 기준에 맞춰 선택하세요.
